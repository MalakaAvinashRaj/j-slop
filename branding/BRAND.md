# J-Slop

Room for better ideas.

Original logo: a J-shaped return beneath two feed lines, suggesting filtering noise while preserving the useful signal. The SVG and raster icons were drawn for this project without stock assets, third-party icons, or downloaded fonts. Typography uses the operating system’s default font.

Palette: ink #242332, mint #A7EDCA, canvas #F7F7F9. Keep surfaces quiet, spacing generous, labels clear, and motion brief. Respect reduced-motion preferences.

Apple is a benchmark for clarity and interaction quality, not a source of branding or assets. These original assets do not establish trademark clearance for the J-Slop name.
